# scayle/composables

Home for composables specific to the Scayle CMS provider (e.g. editor/preview
hooks), mirroring `contentful/composables/` and `storyblok/composables/`.

Empty by design: the Scayle default provider has no visual editor, so it needs no
provider-specific composables yet. This folder exists to keep the provider layout
consistent so any future provider-specific composable has a canonical home.
