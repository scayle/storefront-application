# Documentation

The developer guides next to the code of the Storefront Application V3. The [SCAYLE Resource Center](https://scayle.dev/documentation/storefront/storefront-application-v3/introduction/what-is-storefront-v3)
covers the concepts, features, and configuration. These guides hold what the code and its JSDoc do
not say: conventions, pitfalls, and procedures outside the repository.

## Rules and conventions

- [Glossary](./GLOSSARY.md): The terms to use in code, comments, and docs.
- [Testing Guidelines](./testing-guidelines.md): What to test, how to run tests, fixtures, mocks, and coverage thresholds.
- [Observability](./observability.md): The rules for log lines, local tracing with Jaeger, the span tree of a render, and adding instrumentations.
- [Styling](./styling.md): Panel-driven colors and the pitfalls of changing tokens, fonts, breakpoints, and per-shop colors.

## Features

- [Tracking](./GA4-TRACKING.md): The GTM context, the event push pipeline, and the event list.
- [SCAYLE Analytics](./SCAYLE-ANALYTICS.md): The native analytics pipeline, consent behavior, and how to verify events.

## CMS

- [Amplience](./cms/AMPLIENCE.md): Extending the content model, importing into an existing hub, and bootstrapping a hub.
